# 🌿 나의 숲 — 나만의 기록장 (PWA)

생각 정리 · 메모 · 계획 · 매일 루틴을 섹션별로 나눠 기록하는 앱이에요.

## 파일 구성
```
index.html      앱 화면
style.css       디자인 (어두운 초록 + 아이보리)
app.js          기능 전체
manifest.json   홈 화면 설치 정보
sw.js           서비스워커 (오프라인 실행, 알림)
icons/          앱 아이콘
```

## 휴대폰에 설치하기
PWA는 **https 주소**에 올려야 설치·알림이 동작해요. 가장 쉬운 방법:

**Netlify Drop (가입 1분, 무료)**
1. https://app.netlify.com/drop 접속
2. 이 폴더(grove) 전체를 끌어다 놓기
3. 생성된 https 주소를 휴대폰에서 열기

**GitHub Pages**
1. 새 저장소에 이 파일들을 그대로 업로드
2. Settings → Pages → Branch: main / root → Save
3. `https://아이디.github.io/저장소이름/` 접속

그다음
- **안드로이드(크롬)**: 메뉴(⋮) → "앱 설치" 또는 앱 안 설정 → "설치" 버튼
- **아이폰(Safari)**: 공유 버튼 → "홈 화면에 추가"

## 알림
설정 → "루틴 시간 알림" 켜기. 루틴에 시간을 정해두면 그 시간에 알려줘요.
- 앱이 열려 있거나 백그라운드에 있을 때 가장 확실하게 와요.
- 안드로이드에 설치하면 앱을 닫아도 주기적으로 확인해요 (크롬이 정하는 간격이라 몇 분~수십 분 늦을 수 있어요).
- 아이폰은 iOS 16.4 이상, 홈 화면에 추가한 아이콘으로 연 상태에서만 알림 권한을 줄 수 있어요.

## 데이터
기록은 그 기기의 브라우저 안에만 저장돼요. 설정 → 백업에서 .json 파일로 내보내고 불러올 수 있어요.

## 수정 후 업데이트할 때
`sw.js` 맨 위의 `VERSION` 값을 바꿔야(예: v1.0.1) 설치된 앱이 새 버전을 받아요.
